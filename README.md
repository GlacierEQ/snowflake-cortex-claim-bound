# Cortex Claim Bound

**Lens:** governed data-cloud AI claims (Snowflake-class)  
**Innovation:** Natural-language data claims must bind the exact claim text to unique registered query IDs and to the exact accepted query-ID registry before the claim can pass the citation gate.

Pairs conceptually with `snowflake-query-intent-ledger`, but no exercised integration is claimed yet.

**Important boundary:** a registered query citation proves citation registration, not semantic entailment. This repo does not prove that query results actually support the natural-language conclusion; that requires result-aware evidence verification beyond this gate.
